## Description
This program takes a few simple user inputs and decides what 
album, from a list, to assign to the user. The program requires
the 3rd party library sys in order to exit the program when a 
mistake is made. The repository contains the project file, the 
previous proposal, this README, and the requirements for running 
this program.

I wish to be able to take this program to the next level and have 
all the additional features listed in the proposal. Due to 
regrettable time constraints, I had to simplify parts of the code
in order to have something to submit. I would definitely like to 
at least move this program to pygame and include the color changing
background, just to add a little fun to the program. I intend to 
return to the project once the semester is over to add all the functions.
